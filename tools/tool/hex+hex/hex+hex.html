how to calculate (hex + hex)

Example

  • Input:

    • First Input : A2F
    • Second Input : 25D

  • Conversion:

    • A2F → Integer: 101000101111
    • 25D → Integer: 001001011101

  • Sum:

    • Integer: 101000101111 + 001001011101 = 110010001100

  • Output:

    • Binary Output: 110010001100
    • Hex Output: C8C
